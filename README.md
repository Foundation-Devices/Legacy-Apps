# Legacy Apps

This repository only hosts the public releases of the Passport Prime **Legacy mode** apps.

It does not contain any source code. The apps are developed in the
[KeyOS](https://github.com/Foundation-Devices/KeyOS) repository:

| App | Source |
| --- | --- |
| Legacy emulator | [apps/gui-app-emu-flux](https://github.com/Foundation-Devices/KeyOS/tree/main/apps/gui-app-emu-flux) |
| Ethereum app | [apps/app-flux-ethereum](https://github.com/Foundation-Devices/KeyOS/tree/main/apps/app-flux-ethereum) |
| Solana app | [apps/app-flux-solana](https://github.com/Foundation-Devices/KeyOS/tree/main/apps/app-flux-solana) |

## Downloads
